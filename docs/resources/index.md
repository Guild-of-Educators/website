# Resources

Learning resources for educators: books, guides, tutorials, and courses that help
you teach programming and computing well. We cover Python, but also other tools
educators use, such as Scratch.

Each resource has its own page and one or more tags. A resource can have as many
tags as make sense, so it shows up under every relevant heading below.

Know a great resource that's missing? See [Contributing Resources](contributing.md).
